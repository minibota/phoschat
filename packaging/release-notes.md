## PhosChat 0.2.0 preview

- Switch between light and dark phosphor themes. Keep each conversation in its own compact window.
- Find IRC channels on connected networks and browse a curated directory of servers and communities.
- Connect a Telegram user account through TDLib. Setup requires your own Telegram API ID and API hash.
- Try Slack through browser authorization with PKCE or an approved workspace user token. Workspace policy can require administrator approval.

IRC remains the established provider. The Telegram and Slack integrations are
previews, with live sign-in and compatibility still to be confirmed across
workspaces, accounts and operating systems. See the
[provider setup guide](https://github.com/minibota/phoschat/blob/main/README.md)
for requirements and current coverage.

Download the x86-64 installer for Windows, Fedora, Debian or Flatpak. Use
[the packaging guide](https://github.com/minibota/phoschat/blob/main/docs/packaging.md)
to install your package and check it against `SHA256SUMS`.
